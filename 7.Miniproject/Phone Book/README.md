# Phone Book — Personal Contacts

A responsive, browser-based phone book built from the Python mini-project. It supports adding, searching, editing, sorting, and deleting contacts. Phone numbers are validated as exactly 10 digits, can be tapped to call, and can be copied with one click. A `/` keyboard shortcut jumps to search. Contact data is saved in the browser on the current device using `localStorage`; no account or server is needed.

## Run it

Open `index.html` in a modern browser. To publish it, upload `index.html` to a static host such as GitHub Pages, Netlify, or Vercel. The app is self-contained; the optional Google Font import falls back to system fonts if offline.
